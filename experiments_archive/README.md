## 2. 新记录的登记与收尾

归档规范以[第一阶段规划第 6.1 节](../research_planning/02_phase_one_plan.md#61-保存与归档)为准；打包操作见[指导第 9 节](../research_planning/03_next_steps_guide.md#9-第一轮结束时留下什么)。本索引不另定义实验协议。

每次实验或重要分析收尾时：

1. 在独立运行目录保存脚本或准确命令、配置、输入来源、输出及摘要；正式实验保存协议要求的预测、标签和参数。失败和中断也登记。
2. 摘要说明目的、实际完成项、偏离、结果、解释边界及未完成项；不能用计划命令代替执行记录。
3. 停止写入运行目录后，按协议打包、核验并入库；后续分析建立新记录，不修改已封存运行。
4. 在本页新增一行和必要的证据链接，分别更新执行、入库与备份状态。记录备份位置和核验依据，不在未核验时标为完成。
5. 更新[研究进展与决策记录](../research_planning/04_progress_and_decisions.md)，说明这轮改变了哪些判断，以及下一项工作。

探索发现只有在保存可复查的计算过程和输出后，才登记为独立分析产物。只在对话或进展页摘录的数字需明确标为待归档。

本页是人工维护的索引。新增条目或文件并不自动完成打包、Git 提交或异地备份。
