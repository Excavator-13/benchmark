## 1. 研究范围

以职业子类中的实际技能需求定义共享场景关系，构造可用于不同预测粒度的统一技能图。职业需求结构相近是关系先验，其跨场景适用性与预测收益仍待检验。本定义独立于发布图，不使用发布图行重复数。

首批仅使用 `dataset/demand/r2.parquet` 的 count。大类补充暂缓，不因缺少层级映射阻塞；公司／地区来源、趋势加权、自适应融合与预测训练不在本批。图节点是 skill；预测节点保留 `(目标上下文, skill)`。

## 2. 数据与时间边界

主切分使用 2021-01 至 2023-03 共 27 个唯一月份，不按重叠窗口重复累计。2023-04 至 2023-12 不进入分数、稀疏化或趋势审计。校验整数键、`(r2_id, skill_id)` 唯一、完整职业×技能网格、连续月份及训练值有限非负。发布源预期职业 0..51、技能 0..2334；不符即停，不静默取交集。fixture 支持非连续 ID 和小网格。

按源表精度读取训练列，以 float64 计算，不经过旧 loader 的 float32 narrowing；复用键排序与月份规范，不修改旧 loader。文件哈希用于来源追踪，规范化训练数组、键和月份哈希用于科学输入身份。未使用月份扰动可改变文件哈希，不得改变图和趋势数值。

图在训练观察期末拟合，验证／测试期间固定；不宣称各早期训练窗口当时已获得此图。训练期内部回测须按各折截止重新拟合并另记身份，本批不自动支持回测。

## 3. 两个分数候选

定义 `x[s,c] = sum_t demand[c,s,t]`，t 为上述 27 个月；`b[s,c] = 1[x[s,c] > 0]`。表中有行不代表有需求。

1. 职业集合 Jaccard：`J(s,u) = sum_c b[s,c]*b[u,c] / sum_c max(b[s,c],b[u,c])`；空并集为 0。
2. 需求分布余弦：`p[s,c] = x[s,c] / sum_c x[s,c]`，`C(s,u) = dot(p[s],p[u]) / (norm(p[s])*norm(p[u]))`。全零向量与任何技能分数为 0；余弦与直接对 x 求余弦等价，关系表达职业构成相似，不能把总需求大小本身解释为关系强度。

float64 运算，分数非负对称且去自关系。微小舍入越界可裁回 [0,1]，明显越界／非有限失败。全零技能保留为孤立节点。两个候选独立，不相加、不依趋势或测试排名选胜者。

## 4. 统一稀疏化

逐技能取正分的前 `k=10` 个其他技能，不足取全部。按分数降序、精确平分时 skill ID 升序；记录第 k 名边界平分规模与受影响节点数。k 是本批执行选择，不是用户逐参数确认，不因测试成绩调整。

取有向选择的无向并集：任一端选择即保留，权重为原相似度。保存完整节点、定向选择，以及 `skill_a < skill_b` 唯一边及 float64 score。无自环／重复／零分边。并集后度可大于 10；无向边数 ≤N*k，双向展开 ≤2*N*k。

首批只含两候选。结构退化时保存限制并修订条件，不静默扩大搜索或强迫非空图。实际图冻结仍需审计和研究侧接受。

## 5. 到预测粒度的映射

首批审计 `r0/region/r2` 完整网格。全局边 `{s,u}` 在目标每个上下文 c 内复用为 `(c,s)↔(c,u)`，分数不变，不跨上下文、不按当地活跃度删边／节点。目标只读取身份键，需求数值不进入映射。保存规范目标节点顺序与哈希、映射边数和隔离证明；用隐式映射与逐上下文统计避免复制全部边。

目标每个上下文技能集必须与源完全相同；缺失、额外、重复和不完整网格失败，不取交集。全零目标节点仍保留；若做分组覆盖分析，仅使用目标训练期值并另记边界，不影响图。

结构复用不等于预测收益。旧 runner 的发布图／二值无权均值约束保留，禁止塞入分数产物或静默丢权；传播规则与对应打乱对照留给 T010 软件和比较方案。

## 6. 结构与趋势审计

逐候选报告：来源时间／身份、全零技能、活跃职业数、原始正分关系密度、分数分布、top-k 平分、边数、覆盖／孤立、度、连通分量、权重分布、需求量／职业覆盖广度与度的关系，以及两候选边集 Jaccard。覆盖分别以完整技能集和训练活跃技能作分母；满分／平分集中须披露辨别力限制。

趋势只审计选中边在各职业子类的行为，不参与构图／筛选／加权。每条边每个职业在 27 月上取一阶差分（26 点）Pearson 相关；两端各至少 12 个正需求月份，且差分方差均非零才可计算。否则按优先顺序记历史不足、差分恒定，相关为 null，不写成 0 或负证据。每条边记录合格／不足／恒定场景数及合格场景相关分布；总体记录正／零／负相关数和共同零月份比例。无合格场景的边为未知，仍保留。

12 月仅是描述性资格规则，不代表显著性或可靠性证明。相关受短历史、共同冲击和低计数噪声影响；场景方向相反提示异质性，未发现反向不证明迁移有效。全程不读取验证／测试值。

## 7. 成本、产物和验收

CPU 顺序执行，默认每块 256 技能算分并保留 top-k，避免多份 N×N 矩阵；趋势按边分块，避免全量技能对×职业 Python 循环。分数／构图／映射／趋势分别计时，记录峰值 RSS。构图和趋势各设 30 分钟墙钟上限，进程峰值 RSS 上限 2 GiB；需监控和进度，超限保留 interrupted 及已完成阶段，不减节点／月份、不自动重启。启动前记录设备、依赖、线程与资源余量。

产物包括：实际协议及哈希、源／目标身份、节点、训练职业分布、两候选边表／分数／定向选择、结构／映射／趋势审计、命令、代码基准及实际差异身份、环境、计时和终态。唯一输出身份且拒绝覆盖；失败／中断不标成功。数值数组放 artifact 子目录，可读摘要和 manifest 版本管理，不为单次输出改忽略规则。
