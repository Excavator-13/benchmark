## 1. 与既有协议的关系

继承 [P01 协议](../P01/protocol.md) 的节点身份、count 数据、L6/H3 主切分、训练观察期、验证原始单位 MSE 选模、原始单位主指标、固定分组、五项朴素参照、记录要求及 §6.2 重复性／收益门槛。训练输入只使用对应起点的六个月；每个节点／窗口重置隐藏状态，训练参数在验证与测试阶段固定。

本版本改动的是输入／目标的统一尺度、优化更新的覆盖单位、预算与梯度裁剪，并增加纯时序 LSTM。下文统一 RMS 缩放取代 P01 §3.3 的逐节点标准化公式用于这批神经模型；仍遵守同一训练月份边界。逐节点均值、标准差可继续用于既有分组／Ridge，不能误当作本模型预处理参数。

既有 T002 的 raw-count／200 次全批量更新实验保持 `P1-count-L6-H3-v3` 与原骨架身份，不能按本协议解释。新结果与旧结果是不同条件的比较，不构成逐项因果消融；无法仅据改善判定尺度或预算各自的因果贡献。

## 2. 预处理与损失

对每个数据组独立计算一个标量，使用所有任务节点、训练观察期 2021-01 至 2023-03 的 27 个唯一月份：

`s = max(1, sqrt(sum(y[v,t]^2) / (N * 27)))`。

用 float64 积累统计量；保存 s、节点／月份身份与来源。禁止按重叠窗口重复计算、加入验证／测试月份，或按 seed／模型／图分别拟合。输入和目标均为 `y / s`，不中心化、不逐节点缩放、不裁剪原始需求；模型计算为 float32，反变换 `prediction = s * model_output`，原始单位评分使用 float64 归约。

训练损失为所有被该次更新覆盖的节点和三个 horizon 的平均缩放后平方误差。这等于相同预测下原始单位 MSE 除以同一个 `s^2`，保持节点及 horizon 的相对误差权重；不等于逐节点标准差归一化后的等权误差。统一缩放有助于匹配输出量级，但不保证所有尾部输入都脱离饱和区，须记录输入／目标分位数、隐状态绝对值大于 0.99 的比例及输出尺度作诊断。

默认不截断负预测。原始预测为主结果，同时按 P01 的既有口径附列裁剪结果与负预测比例；不得以测试成绩选择裁剪规则。

## 3. 模型与优化单位

| 项 | 定义 |
| --- | --- |
| GRU | 共享 `GRU(1,32)`，单层、单向、有 bias、dropout=0；取最后输出隐状态，接共享 `Linear(32,3)`；理论参数量 3,459，运行时实测 |
| LSTM | 共享 `LSTM(1,32)`，其余配置同上；每个节点／窗口的 h、c 都从零开始，取最后输出隐状态，不取 cell state；理论参数量 4,579，运行时实测 |
| 初始化 | 对应 PyTorch 模块默认初始化，构建前设模型 seed；同架构的候选学习率与后续图分支以相同 seed 起点配对 |
| 每次更新 | 一个完整训练窗口的全部节点／horizon；上下文按既有规范顺序分块，累积梯度后才执行一次 Adam step |
| 窗口顺序 | 每轮依次遍历起点 0..18，循环重复；不打乱、不丢弃窗口，每轮 19 次更新 |
| 全局权重 | 每个上下文 chunk 的平方误差和除以 `N*3` 再 backward；不是各 chunk 均值等权，更不是每个上下文独立更新 |
| 图兼容 | 后续图比较保留每个上下文完整节点／邻接，禁止将图邻居切断后称为原均值聚合；自身分支采用相同节点覆盖与更新顺序 |
| 优化器 | Adam，学习率有限候选 `{1e-3, 3e-3}`；betas=(0.9,0.999)、eps=1e-8、weight_decay=0、amsgrad=false，无 scheduler |
| 梯度裁剪 | 全部上下文梯度累积后、step 前做全模型 L2 norm 裁剪，max_norm=1；保存裁剪前 norm 和是否触发 |
| 预算 | 每次完整拟合 100 轮＝1,900 次更新；不按某条曲线自动延长，不做性能早停 |
| 诊断节点 | 第 10／50／100 轮，即更新 190／950／1,900；为同一轨迹的检查位置，不是三次独立拟合或挑选预算的候选 |
| 验证／checkpoint | 初始化（step=0）及每轮结束时验证，原始单位 MSE 选 step>0 的 checkpoint；精确平局选更早更新。保存模型、优化器、预处理、轮／步／下一窗口、RNG 与历史，按轮边界原子发布 |
| 设备 | 首批采用 CPU float32、torch／BLAS 单线程、确定性算法、一次一个 worker；MPS/CUDA／多线程另记条件，不自动混入 |

训练期间的在线训练误差要标记为“不同更新前参数上的累计值”，不能冒称某个固定 checkpoint 的训练 MSE。另在初始化、诊断节点及最终被选 checkpoint 上用固定参数重评训练集，供学习有效性判断；这些操作只读训练／验证数据。

## 4. 有限选择范围与重复

按 `r0 → region → r2` 逐组执行；每组先 GRU，再 LSTM。不得从更大粒度或剩余全矩阵直接开始。

每个数据组／编码器在 seed=0 下完整比较两个学习率；以各候选的最优验证原始单位 MSE 选学习率，精确平局选择较小学习率。选中的 seed=0 轨迹复用为该条件的重复 a，不再重训伪造独立筛查。固定该学习率后完成 seeds=1、2 的 a，以及三个 seeds 各自的 b。开发范围为六个“数据组×编码器”块，每块最多 7 次完整拟合：2 次候选筛查＋2 次新增 seed 的 a＋3 次 b，总上限 42 次。失败／中断尝试单独保留并计入时间上限，不靠失败重试无限增加搜索。

配置选择只读验证分数，b 不承担二次选择。选择结果、候选验证分数及淘汰理由全部保存；不按测试、最有利 seed 或分组指标选模型。T007 在每组沿用 T006 已选 GRU 训练条件，对自身／真实／打乱分支统一条件，不另给某个分支额外的优化搜索预算；alpha 清单和选择规则届时在比较前冻结。

每个数据组／编码器先完成以下验证期有效性检查与重复检查，再冻结其测试报告配置。未通过时保留诊断，不增加本版本候选或用测试解锁门槛。旧测试结果已被查看，仍披露这一事实；新方案不能冒称全新盲测。

## 5. 训练有效性检查

以下为事先规定的开发停止判据，用于避免重复无信息图比较；不是显著性检验，也不是图收益结论。对固定学习率的重复 a、三个 seeds 计算，b 仅核对重复性。

1. **完整性与数值：** 所有完成轨迹覆盖全部训练节点／窗口，损失、梯度、参数与预测有限；预处理只用训练观察期，checkpoint 与配置身份相符。数值异常立即停止该块，不把异常 seed 排除后计算“成功均值”。
2. **确有学习：** 至少 2/3 seeds 在所选 checkpoint 上，固定参数的训练原始单位 MSE 比初始化降低至少 10%，且验证 MSE 比初始化降低至少 5%。初始化评分只作诊断，不作为可被选中的 checkpoint。
3. **脱离近零解：** 至少 2/3 seeds 的验证 MAE 相对原始单位 Zero 基线改善至少 5%。若 Zero MAE=0，不计算改善率，转入全零目标诊断，不宣称通过。
4. **预算末段检查：** 对每条轨迹，比较前 80 轮最佳验证 MSE `b80` 与全部 100 轮最佳值 `b100`，定义 `(b80-b100)/max(1e-12,b80)`；两者均为零时记 0。至少 2/3 seeds 的该值不超过 1%，否则标记仍受预算限制，先诊断，不直接扩大正式图矩阵。最优点恰在末轮本身不等于失败，本条件也不证明充分收敛。
5. **同条件重复：** CPU 的 a/b 归一化 MAE 差按 P01 §6.2 不超过 1e-6，并报告预测最大绝对差；使用验证预测先验收，正式测试产出后对测试也核对。超限先查条件，不归入初始化方差。

上述条件须同时满足才记该数据组／编码器 `learning_ready`。它只说明获得了比先前更有信息的开发对照，不能证明时序结构已充分学到；附列“验证输入置零”的预测变化／MAE诊断，但不按该探针调参。LastValue 与 Ridge 的验证成绩必须同表报告；不强制神经基线打败它们才算学动，也不因 `learning_ready` 就满足图收益、RMSE 约束或时间泛化条件。

GRU 未通过的数据组不展开 T007；LSTM 未通过时记录另一编码器的诊断，不能替换为有利 seed。只完成部分数据组时，任务保留部分进度；缩小研究范围或追加候选／预算需有新的记录决定，旧失败不覆盖。门槛数值是本次规划选择，不能用新测试成绩事后放宽。

## 6. 成本与停止线

这些是本批次的保守执行上限，不是已实测耗时或已租用资源。机器可为本机 Mac 或仍可用的原 Windows CPU 环境；使用哪台，在实际运行前写入批次身份。不得在同一 a/b 配对中切换机器／库版本，跨设备单列。

| 范围 | 上限／启动条件 |
| --- | --- |
| 并发／CPU | 一个训练 worker，单线程；避免占用多份模型／数据，禁止自动并行扩大范围 |
| 内存／磁盘 | worker 进程树采样 RSS 上限 8 GiB；启动时主机可用内存至少 6 GiB、目标盘空闲至少 5 GiB；监控间隔不超过 5 s，超过上限停止。采样不是内存硬隔离保证 |
| 成本样本 | 每块首个候选先到 10 轮（190 更新），连同读数、初始化和诊断最多 15 min；通过成本门后只按相同条件继续同一轨迹，不把样本再算一次拟合 |
| 单次拟合 | 墙钟最多 60 min，含本轨迹的成本样本与 checkpoint I/O；不能以恢复新身份重置累计时间预算 |
| 整个 T006 开发批次 | 累计执行墙钟上限 12 h，包含候选、重复、失败、中断、成本样本和检查；不含无人运行时的等待时间。达到上限暂停并保存恢复点，不自动启动剩余块 |
| 稳态估时 | 取第 6..10 轮完整耗时中位数 `t`（含训练、验证、诊断与 checkpoint），用 `setup + 2*100*t` 估计完整拟合，再预留 30% 给末端推理／检查；未测编码器／数据组成本明确为未知 |

正式展开每块前，`cost.json` 须给出本机实测的单次完整拟合上界、剩余拟合数及累计已用时间；只有预测的本块剩余成本＋已用时间在总上限内，且单次上界不超过单次上限，才放行该块。不把 GRU 的速度直接作为 LSTM 测量；尚未到达的数据块没有实测，不预先批量排程。稳态样本不足、进程监控失效或预估超限则暂停该块。

依赖缺失、输入身份不符、配置／协议不一致、非有限值、重复差超限、内存／磁盘／时间超限及 checkpoint 发布失败均停止受影响块并保留记录。恢复必须同时满足新身份、可验证 checkpoint、相同计算条件和未耗尽的累计成本额度；中断在轮内时只从最后完整轮恢复，重算部分也计入成本。

## 7. 软件与保存边界

当前冻结 runner 不支持本协议。新增能力须先走 OpenSpec 实现、独立验证与研究侧软件就绪验收；研究侧交接要求见 [T005 方案报告 §5](../../reports/p02-t005-20261107-01/report.md#5-实现交接与后续入口)。本协议不提供尚不存在的 CLI 参数或可运行命令。

预检须机器可读地产出 pass/fail，覆盖协议／源码／数据／环境身份、CPU／线程／依赖、资源可用性、旧控制器冲突、输出不覆盖与恢复身份。模型训练接口不接收测试标签；验证期方案选择与有效性检查完成后才由报告环节生成测试预测。

实际实验按 P01 §6.1 保存来源、条件、预处理 s、节点／时间／分组身份、所有候选验证分数、所选权重、训练／验证历史、恢复与成本记录；正式报告的预测和标签足以重算原始单位指标。重复检查使用已保存证据，不重新训练替代原记录。小型记录与大型数组遵守现有保存政策，不新增逐 run 的忽略例外；封存、commit、push 与备份按各自授权执行。
