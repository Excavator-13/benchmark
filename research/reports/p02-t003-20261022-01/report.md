## 2. 诊断：实现、尺度与图语义

### 2.1 实现

- 检查记录的 26 个源码文件在三个批次都与当前检出逐字节一致或仅 CRLF/LF 差异：原始字节 5/26 相同，换行归一化后 26/26 相同，无不符项。运行实现即 T001 归档核验的同一套骨架；记录来源 commit 为 `815f1cc`（r0/region）与 `2ca56dd`（r2）。
- 参数量 3,459（GRU 3,360 + head 99），与冻结骨架一致；图分支无额外可学习参数，孤立节点消息为 0，聚合为入边去重均值——由实现源码与 T001 归档验证覆盖，本轮的图/自身/打乱差值与这些语义一致，没有发现实现越界。
- 训练循环按 repeat 检查的 `condition_identity` 记录：**每个 epoch 一次全批量 Adam 步**（`lr=1e-3`）、200 epoch、原始 count 的 MSE、无早停、无梯度裁剪。即整条训练曲线只有 200 次参数更新；同一记录确认三个方法共用同一条件。

### 2.2 尺度与学习进程

- 90 个正式拟合的验证 MSE 最优 epoch 全部是 `200`，即预算终点仍在改善；30 个拟合的最优验证 MSE 在各组内部高度重叠（`r0` 15,973,939–15,976,316；`region` 558,395–558,693；`r2` 34,719–34,746），不像是三种不同的解。
- 真实图的测试 MAE 分别只有 `Zero` 基线（恒预测 0）的 99.44% / 97.90% / 96.64%，RMSE 为 99.95% / 99.82% / 97.51%；验证集上 RMSE 比例同样为 99.95% / 99.78% / 99.56%。模型在两个划分上都接近「预测 0」的无信息解。
- 误差主体在 `high` 活跃度组（绝对误差贡献 99.91% / 99.32% / 97.15%）。该组真实图 MAE 1307.32 / 257.04 / 101.01 ≈ `Zero` 1315.60 / 263.62 / 106.07，是 `LastValue` 214.07 / 55.21 / 27.67 的 6.11 / 4.66 / 3.65 倍；同时三条 horizon 的 MAE 几乎持平（`r0` 1146.83 / 1184.57 / 1145.10），没有随预测步长衰减的输入跟踪迹象。也就是说，承担几乎全部误差的节点上，编码器没有学到可用的输入→预测映射。另外同一骨架在三组学到不同偏移：`r2` 的真实图约 37% 的预测为负（三个 seed 一致），而 `r0`/`region` 为 0，输出更像由输出头偏移主导而非输入驱动。
- 由此最可能的解释是训练预算与原始 count 尺度的组合：200 次全批量 Adam 步只能把输出头移到一个小偏差附近，尚未拟合输入；这与「所有方法验证最优都在预算终点」「模型接近 Zero」「高活跃组毫无改善」一致。该解释是推断，不是已证明的因果（见 §3）。

### 2.3 图语义

- 有非自身邻居的节点占 r0 13.45%、region 13.37%、r2 8.39%（与 P01 T002/T006 的覆盖数一致），图最多只能影响这部分节点。
- 覆盖节点上，真实图相对自身分支：r0 +1.04%（改善）、region −0.60%（变差）、r2 −15.20%（变差），方向随数据组变化；其中 r2 的退化在总体中被 91.6% 的无邻居节点摊薄，只表现为总体 −0.98%。
- 覆盖节点上，真实图相对三图平均：r0 −0.0002%、region +0.11%、r2 +1.74%，只在 r2 超过 1% 且未通过自身对照；其余数据组可忽略。每组 6 份、共 18 份三图汇总检查的状态、成员身份与未挑最弱图标志均为预期值，门槛脚本没有记录状态问题。
- 综合：r2 覆盖节点上真实图明确优于打乱图（+1.74%），说明该处的图结构不是纯噪声；但同一批节点上真实图比自身分支差 15.30%，region/r0 的信号方向相反或可忽略，总体效应又被覆盖率和未训练的主体误差淹没。**用这些结果不能判定「图语义无价值」**，只能说不存在超过 §6.2 门槛的图收益。

## 3. 限制

- 完整预测数组、模型权重与逐 epoch 训练历史仍按原执行报告留在 Windows D 根，本机未核验；因此本报告不能给出预测分布、loss 曲线或梯度范数的直接统计。§2.2 的「接近 Zero / 欠拟合」由已交付的重算指标与最优 epoch 支撑，属于证据充分的解释而非证明。
- 发布图构建时间未知，结论只作固定评测期证据；不涉及跨时间稳健性。
