# Region/count，500 epoch 实验与论文对照

分析日期：2026-10-02。

## 结论

本次实验完整运行，保存指标能够从预测张量独立重算验证，但尚未达到论文的 EvolveGCN-H Region 报告水平，也未证明图模型在当前评估协议下带来收益。更明确的发现是：两个随机种子的表现差异较大，错误高度集中于大需求值，且两个 seed 都落后于同测试集的简单持续性预测基线。

因此，适合将其作为“修复后实现的基线诊断与稳定性分析”，不适合表述为“成功复现论文”“证明图模型更优”或“否定论文结论”。

## 1. 核查范围与证据

- 结果：`benchmark/benchmark-try/graph_method/results/count/region/EvolveGCNH/{0,1}/`。
- 另一份 `benchmark/benchmark-try/benchmark/graph_method/results/...` 下的产物逐文件哈希相同，是重复副本，不能算作额外实验。
- 下载归档：工作区上两级目录下的 `evolvegcn-region-count-results.tar.gz`，其中两份日志均到达 500/500，最终指标与当前文件一致。
- checkpoint：模型 EvolveGCNH，16345 个节点，输入窗口 6，预测跨度 3，seed 分别为 0、1；对应 7 个地区，每地区 2335 条技能序列。
- 张量形状：4 个测试窗口 × 16345 个节点 × 3 个预测步，共 196140 个预测值；两个 seed 的真实值完全一致，预测均为有限数。
- 预测真实值与当前生成的 Region/count 数据逐值匹配，目标起点为第 30、31、32、33 月（从 0 编号），对应 2023 年 7、8、9、10 月开始的三个月预测。
- 四个窗口覆盖 2023 年 7–12 月，重叠月份按不同预测起点分别计入。这里比较的是滚动多步预测误差，不是每月只计一次的六个月误差。
- 从张量以 float64 重算与原 float32 统计结果相符，差异仅为浮点精度量级。
- 归档环境：Tesla T4 15 GB，torch 2.3.0+cu121，torch_geometric 2.4.0，torch_geometric_temporal 0.54.0；记录的提交为 `950a1d8febbf992b8bda061d35f03107d0b18478`。

## 2. 与论文 Table 9 的数值对照

原始来源：NeurIPS 2024《Job-SDF: A Multi-Granularity Dataset for Job Skill Demand Forecasting and Benchmarking》，附录 D.3，PDF 第 21 页 Table 9，Region 列、EvolveGCNH 行。已核对原 PDF 的文字及页面图像。

| 实验 | MAE | RMSE |
|---|---:|---:|
| 论文 EvolveGCN-H | 30.07 ± 22.97 | 166.34 ± 127.04 |
| 当前 seed 0 | 41.08 | 238.96 |
| 当前 seed 1 | 96.18 | 579.50 |
| 当前两个 seed 均值 ± 总体标准差 | 68.63 ± 27.55 | 409.23 ± 170.27 |

当前均值相对论文均值，MAE 高 128.24%，RMSE 高 146.02%；seed 0 单独也分别高约 36.62%、43.66%。seed 1 的 MAE 是 seed 0 的约 2.34 倍，RMSE 约 2.43 倍。

这里的总体标准差使用分母 n，与指南中的汇总口径相同。若使用分母 n−1 的样本标准差，则分别是 MAE 38.96、RMSE 240.80。只有两个 seed，无法据此做可靠的显著性推断；论文的“±”也不能直接视为置信区间或成功复现的容许范围。

论文 Table 6（PDF 第 18 页）中，Region 的 SegRNN 为 MAE 35.92、RMSE 194.73，PreDyGAE 为 35.84、193.94，DLinear 为 35.45、222.14。当前 seed 0 的量级接近这些方法，但数值仍更差；跨协议比较只能提供背景，不能作为公平模型排名。

## 3. 当前测试集上的直接基线比较

基线均从同一份原始需求序列构造，在每个预测起点只使用当时已观察到的历史值，并以与模型完全相同的真实值、窗口及误差公式评估。

| 方法 | MAE | RMSE |
|---|---:|---:|
| 全部预测为 0 | 166.48 | 889.63 |
| 最近一个月的值重复预测未来 3 个月 | 35.31 | 193.85 |
| 最近 6 个月均值重复预测未来 3 个月 | 34.57 | 218.04 |
| 预测月份上一年同月的值 | 50.95 | 327.54 |
| EvolveGCN-H seed 0 | 41.08 | 238.96 |
| EvolveGCN-H seed 1 | 96.18 | 579.50 |

模型优于零预测，表明其输出有一定预测信息，但最近一个月及最近六个月均值基线均在 MAE、RMSE 两个指标上优于两个 seed。这个比较无需依赖论文复现口径，是本次最直接的性能证据。

## 4. 误差诊断

### 4.1 大需求值主导平方误差

真实需求 ≥1000 的预测点占全部预测点约 3.37%，却贡献 seed 0 的 94.88%、seed 1 的 96.56% 平方误差。误差最大的 1% 预测点贡献约 93.05%、91.99% 平方误差。

因此，整体 RMSE 主要由大需求点决定，不能据此概括所有技能都预测得很差，也不能把“长尾任务困难”等同于“低频技能是当前 RMSE 的主要来源”。此处按需求值分组只是诊断，不等同于论文按训练期活跃次数定义的低频技能子集。

### 4.2 seed 1 出现低估与负数预测

真实需求整体均值为 166.48；seed 0 的预测均值为 156.06，平均偏差 −10.42；seed 1 的预测均值为 84.05，平均偏差 −82.43。

seed 0 有约 4.55% 负数预测，最小值 −0.012；seed 1 有约 16.10% 负数预测，最小值 −4260.98。后者在非负需求量任务中暴露出输出约束与稳定性问题。非负约束应作为单独验证的模型设计或后处理方案，不能修改已报告结果后继续声称是同一个实验。

### 4.3 seed 1 的问题集中于测试序列前两个窗口

| 测试目标窗口 | seed 0 MAE / RMSE | seed 1 MAE / RMSE |
|---|---:|---:|
| 2023-07 至 09 | 42.42 / 236.83 | 130.59 / 673.09 |
| 2023-08 至 10 | 36.87 / 183.67 | 165.38 / 848.84 |
| 2023-09 至 11 | 42.09 / 233.21 | 45.33 / 293.83 |
| 2023-10 至 12 | 42.96 / 290.16 | 43.42 / 288.77 |

后两个窗口的 MAE 接近，前两个窗口差距极大。当前运行器在测试分区起点重新初始化递归状态，再随快照递推；这一模式值得检查测试初始状态和历史状态预热。但现有数据无法区分递归状态影响、时间变化和其他优化问题，不能把该原因写成已证实结论。

日志显示两个 seed 的最优验证 MSE 从约 59.82 万、56.75 万下降至 30445.59、70053.06，说明训练过程中验证指标确实改善。日志只记录最优验证损失，缺少完整训练损失曲线和 checkpoint 最优 epoch 元数据，因此不能据此判定过拟合、欠拟合，或断言增加 epoch 一定有帮助。

## 5. 为什么不能直接认定复现失败的原因

论文正文第 4 页声明按时间 9:1:2 划分，K=6、H=3。当前仓库文档与实现采用窗口化后的名义 0.83/0.04/剩余比例，并在两个边界各省略两个窗口：实际 19 个训练窗口、1 个验证窗口、4 个测试窗口，训练目标截至 2023-03、验证目标为 2023-04 至 06。

当前分支的修复记录还包含：以验证集选 checkpoint、目标月份跨分区去重，以及 EvolveGCN-H 权重递归、梯度与状态边界修复。公开共现图也没有独立频次列，当前边权由公开文件的重复行信息构造。相对于论文声明和原发布实现，评估与模型实现都存在差异。

这些差异可能影响表现，但没有受控对照实验，不能将当前与论文的差距归因于某一项修复。归档没有保存完整训练命令、源代码快照或训练数据哈希；当前数据与测试真实值匹配、当前代码与日志可解释实验产物，但尚不足以逐项独立认证服务器运行时的全部设置。

未直接用公开的低频/结构突变行索引切片当前张量，因为必须先确认原 Parquet 行序与当前按 node_keys 排序后的节点映射。不能将未核实映射的子集结果拿去比较论文 Table 10、11。

## 6. 可直接用于汇报的表述

> 在 Region 粒度的技能需求量预测任务中，我们使用修复后的 EvolveGCN-H 实现，以 6 个月历史预测未来 3 个月，分别完成 seed 0 和 seed 1 的 500 epoch 训练。两次实验的平均 MAE 为 68.63、平均 RMSE 为 409.23，高于论文报告的 30.07 和 166.34。由于时间划分、模型选择与递归状态处理存在差异，这一结果不构成对论文数值的严格复现。在当前统一测试集上，两个 seed 均未优于持续性预测基线，并呈现较大的随机种子差异。误差主要集中于高需求值，表现较差的 seed 存在明显低估和负数预测。因此，现阶段证据支持继续研究模型稳定性及高需求序列预测问题，尚不足以确认共现图在该设置下带来有效增益。

## 7. 建议的下一步实验

1. 固定当前评估协议，补充 seed 2、3，保留各 epoch 的训练/验证损失、最优 epoch、源代码提交、训练命令与数据哈希。新增 seed 主要提高稳定性判断的可信度，不能解决协议差异。
2. 在相同协议下跑一个 DLinear 或 SegRNN，对照已算出的持续性基线；将图模型和对照方法的训练、验证、测试月份统一。
3. 针对前两个测试窗口检查递归状态，预先定义用已知历史进行状态预热的方案，并用验证集选择方案，避免根据测试结果反复调参。
4. 将需求缩放/标准化、非负输出约束、学习率调整分别作为独立对照，优先观察高需求组和 seed 稳定性。当前已有 500 epoch，直接延长训练缺少证据支持。
5. 若要论证共现图收益，在统一协议下加入去图或自环图消融；若要论证细粒度更优，还需补充其他粒度，单个 Region 实验无法支持这一结论。
